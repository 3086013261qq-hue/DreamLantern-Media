1. 初始“梦灯笼 / 展开狐妖手札”总入口必须显示并播放：

3. 视频层级：
   - 高于静态 poster / `.dl-scene` 背景；
   - 低于文字、渐变遮罩、标题、按钮、声音控制；
   - 禁止继续使用会把视频压到容器背景后的负 z-index。
