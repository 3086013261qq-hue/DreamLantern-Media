# DreamLantern 21卷视觉资产审计 v1.0

审计日期：2026-10-20

## 结论
当前21个可玩卷并没有21套独立正式主视觉，而是将少量原创生成环境母题反复复用。根据 `asset.manifest.json` 的SHA256核对，21卷缩略图实际只来自9套母题：portal / desert / bamboo / blossom / golden / purple / river / bay / snow。

因此本轮统一处理原则：
- 当前原创生成Poster：全部退出“正式主视觉”身份；
- 可保留文件但统一降级为 `fallback-generated`；
- 正式主视觉改为官方宣传视觉 / 官方PV可用动态源 / 官方静态视觉+DreamLantern FX；
- 无可靠官方视觉时才允许显示旧生成图；
- 绝不因素材缺口修改MVU核心。

## 现有重复组

### portal组
- A01 上古源流
- M11 东方灵族

结论：不同篇章复用同一母题，正式主视觉淘汰，旧图仅作fallback。

### desert组
- A02 西域北山
- M01 下沙篇
- M08 真龙篇

结论：三卷语义完全不同却复用同一沙漠母题；正式主视觉全部淘汰。M01尤其必须换成官方下沙篇视觉。

### bamboo组
- A03 涂山道盟
- M03 王权篇

结论：正式主视觉淘汰。M03有明确官方王权篇视觉，应直接替换。

### blossom组
- A04 月红初世
- A06 月红终局
- M04 月红篇
- M09 镜花缘篇

结论：四卷共用一套花景母题，无法表达篇章差异；正式主视觉全部淘汰。M04与M09均已有强官方宣传素材候选。

### golden组
- A05 道盟变局
- M07 金晨曦篇

结论：正式主视觉淘汰。M07应优先官方金晨曦篇宣传视觉。

### purple组
- A07 南国旧缘
- M06 南国篇
- M12 再入南国篇

结论：A07/M06可共享“南国”视觉语言但不能共享同一张主Poster；M12更不能直接复用。旧图仅fallback。

### river组
- A08 千颜旧缘
- M02 尾生篇
- M05 千颜篇

结论：三个不同主题共用同一河景，正式主视觉全部淘汰。M02有官方尾生宣传素材，M05有官方千颜相关动画视觉。

### bay组
- M10 龙湾篇

结论：虽然未与其它卷重复，但仍为原创意象环境图，不具备原作人物/篇章辨识度；降级fallback。正式位等待官方漫画宣传视觉或可靠官方相关视觉。

### snow组
- M13 新北山篇

结论：未重复，但属于泛雪山意象，不足以代表新北山篇；降级fallback。正式位等待官方漫画宣传视觉。

## 动态Opening审计
当前仓库没有实际MP4 Opening文件，现有 `opening.manifest.json` 中动态资源基本仍为 `video: null`。

正式处理：
- 不强制“每卷都必须MP4”；
- 有稳定合法官方动态源：接入 `official_video`；
- 只有官方平台PV页面：登记来源，使用官方静态宣传视觉 + FX；
- 禁止抓临时token MP4、绕DRM、搬运正片或第三方盗版源；
- `video` 只有在资源真实存在且验收通过时才允许非null。

## 第一批返工顺序
优先返工现代前九卷，因为动画官方素材最充足：
M01 下沙 → M02 尾生 → M03 王权 → M04 月红 → M05 千颜 → M06 南国 → M07 金晨曦 → M08 真龙 → M09 镜花缘。

随后处理古代8卷的“官方素材重组”，最后专项处理M10~M13漫画未动画化素材池。

## 禁止事项
- 不删除MVU核心；
- 不修改时代锁、世界书切换、缘卷业务逻辑；
- 不再生成新的泛东方幻想环境图当正式主视觉；
- 不把搜索引擎缩略图、第三方转载图当官方素材；
- 不伪造MP4或时间码。
