## 入口生命周期

`close()` 改为先隐藏shade、清理overlay/时代/Opening媒体，再恢复总入口DOM状态，并统一调用 `restoreIntroAfterOverlay()`。该函数只处理当前聊天第0条消息内真实存在、可见、连通的入口host；overlay可见、文档隐藏或已dispose时不挂载。沿用已有 `enhanceIntro` 和 `mediaLayer.mountIntro` 的单实例保护，URL仍为manifest中的rukou。

切换聊天时使用 `close(false)`，不在马上销毁的旧聊天host上短暂重挂；文档恢复可见时重试统一恢复hook。选卷事务及enter/click处理、媒体适配器（含音频、双阶段、竞态）、内嵌CSS、默认FX与21卷映射均保持118原字节。

## 全量角色关键词

扫描90个人物正文、65个关联条目，合计155条。全部采用一条固定 `<story_scene>` alias-group regex，并设 `constant=false / selective=true / use_regex=true / position=after_char`；probability保持100，既有depth、enabled、权限、正文不变。

`alias119.py` 从唯一基线重建组，保留既有审核关键词，为同名能力/身份补充复用同组。跨人物身份专题保留原联合召回语义，扩展其中明确列出的角色组，不合并人物身份、不改知识权限。

新增称呼均在已有角色正文、能力或时间线中有独立用例，证据条目和摘录存入 `qa/119-character-alias-audit.json`。故义使用“极北萨摩王故义 / 故义 / 极北萨摩王”；未机械截取“萨摩王”。“月初”“富贵”“二小姐”“小狐狸”等因歧义或泛称排除。环毛粉软怪、小狐狸红线仙没有经资料确认的独立简称，保留专名并记录例外。

正则实测155/155编译，1365项全称/每个alias正向、标签外负向、普通宽泛词负向断言通过。同角色人物/能力/专属条目alias一致。
