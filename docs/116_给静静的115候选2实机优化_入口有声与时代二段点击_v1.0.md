## 1. 优化一：总入口 `rukou.mp4` 默认有声，并提供显式静音按钮

### 1.1 目标体验

用户从初始《梦灯笼》入口进入狐妖手札时：

1. `incoming/mp4_raw/rukou.mp4` 作为总入口视频；
2. **默认目标状态为有声播放**；
3. 入口界面右上角或不遮挡主体的位置提供清晰的声音开关：
   - 有声状态：`🔊` / `关闭声音`；
   - 静音状态：`🔇` / `开启声音`；
4. 用户关闭声音后，本次入口播放立即静音；再次点击恢复原声；
5. 不允许出现“必须额外点击开启原声，视频才开始”的阻塞按钮。

### 1.2 Android / WebView 自动播放兼容规则

移动端通常禁止“无用户手势的带声自动播放”。因此实现必须利用**用户用于打开/展开狐妖手札的那一次 trusted click/tap**作为启动 `rukou.mp4` 有声播放的手势。

优先流程：

`用户点击“展开狐妖手札” -> 同一个trusted gesture中创建/唤醒入口video -> muted=false -> play()`

如果设备/WebView仍拒绝带声播放：

- 不得卡死入口；
- 立即降级为静音播放；
- 保留醒目的 `🔇 开启声音` 开关；
- 用户下一次点击声音按钮时恢复有声播放；
- 不得伪造“默认有声已经成功”。

### 1.3 状态边界

- 入口声音状态只属于展示层；
- 不写MVU；
- 不改变网易云播放器状态；
- 离开入口后要正确pause/release `rukou`，不得后台继续响；
- 再次回到入口时，优先尝试恢复“有声目标状态”，但仍遵守浏览器用户手势限制。

## 2. 优化二：前尘 / 今世改为“双击语义”的二阶段选择

### 2.1 当前问题

候选2中前尘/今世视频已经可以显示，但点击时代卡片会直接进入时代，用户没有先观看动态入口视频的机会。

### 2.2 新交互

每个时代卡片独立执行两阶段点击：

**第一次点击该时代卡片：只预览，不进入。**

- 前尘：开始播放 `incoming/mp4_raw/fengmian.mp4`；
- 今世：开始播放 `incoming/mp4_raw/xiandaifengmian.mp4`；
- 视频从头播放；
- 卡片进入 `previewing / armed` 状态；
- 在卡片上显示轻量提示，例如：`再触一次 · 入前尘` / `再触一次 · 入今世`；
- 本次点击不得写 `_时代`、不得切换世界书、不得进入卷列表。

**第二次点击同一个正在previewing的时代卡片：才真正选择时代。**

- 执行原有稳定业务逻辑；
- 写入对应时代；
- 古代/现代锁规则完全保持原样；
- 进入对应卷列表。

### 2.3 跨卡片切换

若“前尘”正在previewing，用户第一次点击“今世”：

- 立即停止/释放前尘预览video；
- 不进入任何时代；
- 开始今世video；
- 今世成为新的previewing卡；
- 之后再次点击今世才正式进入。

反向同理。

### 2.4 回看要求

- 时代视频必须可以重复回看；
- 从卷列表返回时代选择页时，两个卡片都恢复为“未armed”状态；
- 用户再次第一次点击即可从头播放对应视频；
- 不得因为之前选择过时代就使视频永久失效；
- 现代锁定只限制业务上的“回古代”，不得删除/损坏展示层回看能力；如业务规则不允许进入古代，则古代卡片可允许**只回看视频但不得第二击进入**，并给出明确锁定提示。

## 3. 声音规则

- 本施工单只明确要求**总入口 `rukou.mp4` 默认目标为有声**。
- 前尘/今世两个时代预览视频继续以移动端稳定性优先，可保持静音播放；不要擅自让多个视频同时出声。
- 任意时刻最多一个视频处于active playing状态。
- 打开卷Opening时继续沿用候选2现有逻辑，不得因此破坏21卷Opening自动播放行为。

## 4. 特效与视觉不得回退

候选2已经确认效果良好，因此：

- 默认FX继续保持开启；
- 红线、狐火、花瓣、尘光、卷级profile全部保留；
- 不得为了新的视频点击逻辑关闭FX；
- 不得恢复“特效默认OFF”；
- 不得修改现有封面分配与21卷映射。

## 5. QA硬验收

至少验证以下场景：

1. 用户点击“展开狐妖手札”后，`rukou.mp4` 尝试直接有声播放；支持的环境中无需第二次点击即可听到原声。
2. 若Android/WebView阻止有声自动播放，入口仍立即播放视频（静音降级），声音按钮可一击恢复原声。
3. 入口声音按钮可在🔊/🔇之间往返切换，视频不中断、不重载。
4. 第一次点击“前尘”只播放 `fengmian.mp4`，不进入古代。
5. 第二次点击同一“前尘”才进入古代。
6. 第一次点击“今世”只播放 `xiandaifengmian.mp4`，不进入现代。
7. 第二次点击同一“今世”才进入现代。
8. 前尘previewing时点击今世，只切换预览，不误进入前尘/今世。
9. 返回时代页后可再次从头回看视频。
10. 现代锁定后，不得通过二次点击绕过业务锁返回古代；但展示层回看按2.4执行。
11. 任意时刻只有一个active video；切页/关闭手札后视频释放，无后台残音。
12. 21卷Opening、默认FX、网易云、世界书、时代锁、v1.2.0版本号均无回归。
