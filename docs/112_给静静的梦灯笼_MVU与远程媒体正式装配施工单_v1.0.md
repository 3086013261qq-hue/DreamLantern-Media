## 三、时代首页：彻底废弃“双镜门”

原双镜门方案正式作废，不再使用任何镜子造型。

缘卷首页改为上下两个宽幅动态时代入口：

### 上：前尘 / 古代
远程视频：
`incoming/mp4_raw/fengmian.mp4`

### 下：今世 / 现代
远程视频：
`incoming/mp4_raw/xiandaifengmian.mp4`

要求：
- 两块都是真实 `<video>` 动态背景；
- 通过jsDelivr远程加载；
- 默认静音、循环、playsInline；
- 点击区域覆盖整块入口；
- 视频上叠加标题、简短副标题、渐变遮罩；
- 不能再表现成两块深色矩形卡；
- 视频加载失败时可退回静态封面 + FX，但不能变黑屏；
- 点击后仍调用现有时代选择业务，不改MVU。

建议视觉：
- 上下两块比例约 16:9 或略扁电影卡；
- 中间用一根若隐若现的红线/灯金分隔；
- 卡片边缘不是厚重后台边框，而是轻薄金线+柔光；
- 前尘偏旧金/绯红/雾感；今世偏明亮月白/绯红/青白狐火。

## 四、21卷素材映射：按动画篇章顺序换位，不按文件名同号硬套

用户上传文件的数字顺序遵循动画篇章顺序。
M/A只是用户原始素材标签，不等于梦灯笼的Modern/Ancient正式卷号。

因此：
- 禁止 `M02.mp4 -> 梦灯笼M02` 这种同号直连；
- 禁止 `A05.mp4 -> 梦灯笼A05` 这种同号直连；
- 必须按 `manifest/anime-to-manga-remap.v1.json` 做顺序换位。

处理方法必须简单：

原始数字顺序
→ 查动漫第N篇是什么篇章
→ 用篇章名映射到梦灯笼漫画卷号
→ 写入最终chapterVideos。

不需要为了“认序号”逐帧识别视频内容。

现代明确换位规则：
- 动漫01 下沙篇 -> 梦灯笼 M01 下沙篇
- 动漫07 尾生篇 -> 梦灯笼 M02 尾生篇
- 动漫02 王权篇 -> 梦灯笼 M03 王权篇
- 动漫03 月红篇 -> 梦灯笼 M04 月红篇
- 动漫04 千颜篇 -> 梦灯笼 M05 千颜篇
- 动漫05 南国篇 -> 梦灯笼 M06 南国篇
- 动漫06 竹业篇 -> 历史/回看，不占现代卷位
- 动漫08 金晨曦篇 -> 梦灯笼 M07 主映射
- 动漫09 沐天城篇、动漫10 两生花篇 -> 归入M07相关阶段，不另占现代卷位
- 动漫11 无暮篇 -> 梦灯笼 M08 真龙/无暮阶段
- 动漫12 镜花缘篇 -> 梦灯笼 M09 镜花缘篇
- 动漫13 黄风岭篇 != M13新北山，严禁因数字13相同误绑。

M10龙湾、M11东方灵族、M12再入南国、M13新北山使用用户已经另行挑选的对应素材；不得拿动画13黄风岭填M13。

古代A01-A08仍按梦灯笼古代八卷时间顺序落位，不把原始A文件名数字直接当正式卷号；按用户素材既定动画顺序表做一次换位即可。

完成后：
- `manifest/user-media-runtime.v1.json` 的 `chapterVideos` 必须为21卷最终远程路径；
- `mappingStatus` 改为 `VERIFIED_MANGA_ORDER`；
- 不再保留“mapping-pending”阻断正式播放。

## 五、每卷缘卷卡面与Opening

用户上传的23张JPG文件名乱码不重要。

用途非常简单：
- 选21张作为A01-A08、M01-M13的预览封面；
- 余下2张备用；
- 只要求好看、风格合适，不要求封面图与对应MP4严格同源；
- 不要继续默认使用旧版丑封面。

每卷交互：

缘卷卡面
→ 显示该卷预览封面
→ 点击卡面
→ 打开该卷Opening层
→ 通过jsDelivr播放对应MP4
→ Closing/Skip后回到该卷功能层/进入现有卷选择流程。

MP4要求：
- 保留用户上传素材的原音轨；
- 不额外叠加第二套BGM；
- Android/WebView若禁止未交互有声自动播放，则先静音/显示“点亮梦灯”或播放按钮，用户手势后开启声音；
- 不允许因autoplay限制导致黑屏；
- 关闭Opening时 pause + remove src + load，释放资源；
- 任意时刻最多一个篇章Opening视频活动；
- 若缘音网易云正在播放，手动打开Opening时应暂停/压低缘音，Opening关闭后可恢复；不要两个音源同时轰。

## 七、必须真实可见的特效

本轮最重要验收原则：
“不能只写CSS，必须真的有DOM节点并在Android实机肉眼可见。”

全局轻量特效：
- 1~2根缓慢漂移的红线；
- 少量灯金微尘；
- 稀疏青白狐火；
- 柔和径向光晕；
- 页面切换时轻微淡入/上浮。

卷级可选extra FX：
- 下沙：细沙/暖风微粒；
- 王权：细金剑光、极轻碎光；
- 月红：红线 + 花瓣 + 柔背光；
- 南国：淡紫雾 + 狐火；
- 镜花缘：镜面折光/水纹光；
- 北山/雪域相关：雪尘 + 冷雾。

性能要求：
- 手机端粒子节点尽量 <=14；
- 不依赖canvas；
- `prefers-reduced-motion` 必须降级；
- 动画只做低频、柔和、可见，不做满屏乱飞；
- 特效层 pointer-events:none；
- 特效失败不得影响按钮点击。
