## 四、映射理由

### A01 上古源流 → 竹业篇EP
A01包含东方灵族受传、纯质阳炎传承、避世与东方秘境建立。用户现有01~08 EP中，竹业篇与东方灵族、神火山庄、纯质阳炎视觉体系最接近，因此作为上古源流的主动态视频。

### A02 西域北山 → 下沙篇EP
A02包含梵云飞与厉雪扬的西西域旧缘，下沙篇与该部分直接对应。

### A03 涂山道盟 → 王权篇EP
A03覆盖面具组织、王权霸业、道盟兵人计划、王权富贵出生等王权/道盟历史。竹业相关内容继续由本卷静态视觉与竹影、剑光、纯质阳炎FX承担；动态EP主视频采用王权篇。

### A04 月红初世 → 月红篇EP
东方月初进入涂山、与涂山红红关系建立以及七夕表白均属于月红主轴，直接对应月红篇。

### A05 道盟变局 → 金晨曦篇EP
A05包含木蔑、翠玉鸣鸾、金晨曦、沐天城危机等内容，金晨曦篇EP作为主视频最贴近该卷核心危机。

### A06 月红终局 → 尾生篇EP
A06前半是月红终局，后半完整承载胡尾生×月啼暇前世悲剧。为避免与A04重复使用同一月红EP，主视频采用尾生篇EP；月红终局由红月、断线、虚空之泪等卷级FX和静态视觉继续表现。

### A07 南国旧缘 → 南国篇EP
平丘月初、欢都落兰及南国政变与南国篇直接对应。

### A08 千颜旧缘 → 千颜篇EP
颜如玉、律笺文、追捕、伏法与续缘直接对应千颜篇。
