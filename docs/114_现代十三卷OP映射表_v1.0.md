## 四、重要语义边界

M10-M13 的后四个绑定是**媒体展示层映射**，作用仅为：

`缘卷预览封面 -> 点击 -> 播放对应远程OP MP4`

它们不改变世界书、时间线、人物、地点、剧情事实源，也不代表：

- 竹业篇正史等于龙湾篇；
- 沐天城篇正史等于东方灵族篇；
- 两生花篇正史等于再入南国篇；
- 黄风岭篇正史等于新北山篇。

因此旧资料中“不得把黄风岭当成新北山正史素材”等内容仍然对**剧情事实/正史声称**有效，但不得再被解释为“禁止M13播放M13.mp4”。本轮用户要求是21段视频完整覆盖21卷的Opening展示层。
