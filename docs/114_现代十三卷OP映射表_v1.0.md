## 一、硬规则

用户上传素材的数字后缀始终表示**动漫篇章顺序**，不是梦灯笼现代卷号。

- `M = OP素材`
- 数字 `01~13` = 动漫篇章顺序
- 禁止把 `M01.mp4` 直接理解为梦灯笼现代卷M01
- 禁止把 `M13.mp4` 直接理解为梦灯笼现代卷M13

动漫篇章顺序固定为：

1. 下沙篇
2. 王权篇
3. 月红篇
4. 千颜篇
5. 南国篇
6. 竹业篇

10. 两生花篇

## 五、运行时要求

机器可读事实源：

`manifest/anime-to-manga-remap.v1.json`

后续静静应按 `modernOrderCrosswalk` 读取 M01-M09 的正式换位；M10-M13 保持未绑定状态，不得为了凑满13卷而错误匹配。

封面层仍可为M10-M13显示预览封面和既有FX/静态fallback；缺少一一对应动画OP并不影响卷本身可玩。
