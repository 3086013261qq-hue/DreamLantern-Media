# 《梦灯笼》MVU背景与特效美化规格 v1.0

> 本规格只定义视觉层。MVU核心、时代锁、缘卷切换、世界书切换、缘忆/缘音业务逻辑全部禁止修改。
> 施工者只能按本规格美化，不得自行更换篇章素材或重新设计功能。

## 1. 当前问题
当前 `ui/dreamlantern.css` 的整体色彩被以下青绿色系统治：
- `#102427`
- `#39534d`
- `#172d30`
- `#1a3030`
- `#182e30`
- `#233c3d`
- `rgba(24,48,48,.87)`

这些颜色同时出现在主壳、按钮、卡片、音乐区、Opening遮罩，造成实机“整块绿黑色”的观感，与《狐妖小红娘》的红线、苦情树、狐火、缘契意象不匹配。

## 2. 新视觉主题：夜漆·红线·灯金
禁止再以固定青绿色为主色。

建议基础Token：
```css
--dl-bg-deep: #110d16;
--dl-bg-wine: #24131d;
--dl-bg-ink: #15131b;
--dl-surface: rgba(32,20,29,.78);
--dl-surface-strong: rgba(38,22,31,.90);
--dl-surface-soft: rgba(58,31,40,.52);
--dl-line: rgba(226,183,131,.26);
--dl-gold: #ddb77d;
--dl-gold-light: #f2d6a5;
--dl-red: #b95b68;
--dl-red-light: #e38b94;
--dl-ivory: #f3eadb;
--dl-muted: #c9bcb3;
--dl-foxfire: #c8e6dd;
--dl-shadow: rgba(5,2,8,.58);
```

说明：
- 主基调是黑紫/酒红/暖金，不是大红大金婚庆风。
- 狐火青白只做微量高光，不得重新把全UI染成青绿。
- 当前篇章可以提供少量动态主题色，但只用于光晕/边缘，不覆盖基础视觉体系。

## 3. 主壳背景 `.dl-paper`
目标：从“绿色实色面板”改为“深色半透明漆面 + 当前篇章模糊视觉 + 暖金纸纹”。

结构建议：
1. 最底层：当前篇章官方主视觉（若有），使用CSS变量 `--dl-current-art`；
2. 中层：`blur(18~28px)` + `scale(1.08)`，透明度控制在0.22~0.34；
3. 暗化层：黑紫到酒红渐变；
4. 顶层：极轻纸纹/噪点（opacity 0.05~0.10）。

禁止：
- 直接把清晰人物图铺满导致正文看不清；
- 大面积绿色径向渐变；
- 固定某一卷海报当所有页面背景。

无当前篇章或外部图加载失败时，回退到纯程序背景：
`#110d16 -> #24131d` 的暗色渐变 + 微弱金尘。

## 4. 玻璃层 / 卡片
`.dl-card / .dl-memory / .dl-music / tabs区域`：
- 背景：`rgba(28,18,27,.70~.84)`；
- `backdrop-filter: blur(14px) saturate(.9)`；
- 边框：暖金0.18~0.30透明度；
- 阴影：黑紫外阴影 + 极轻金色内描边；
- 卡片圆角控制在14~20px，取消过度“墓碑拱门”感。

现有 `.dl-card` 的 `border-radius:90px 90px 13px 13px` 应收敛。
建议：`18px` 或 `20px 20px 14px 14px`。

## 5. 顶部与品牌
`狐妖手札 / DREAM LANTERN`：
- 中文品牌：暖象牙或浅金；
- 英文副标：低饱和金灰；
- 顶部分隔线改为“中间亮、两端透明”的细线，不要硬边框贯穿；
- 可在标题附近加入极细红线弧迹，但不能遮文字。

## 6. Tabs：缘卷 / 缘忆 / 缘音
普通状态：
- 透明深色玻璃；
- 字色 `#c9bcb3`；
- 边框弱。

激活状态：
- 不再使用青绿背景；
- 使用酒红→暗红渐变 + 暖金底边；
- 可有1次200~300ms红线扫过；
- 不持续闪烁。

## 7. 按钮
主按钮（如“由此入梦”）：
- 低饱和暖金渐变或酒红+金边；
- 按下时仅轻微缩放 `0.98` + 光晕收缩；
- 禁止青绿实心按钮。

次按钮：
- 深色玻璃 + 金色细边；
- hover不是必要条件，Android触控必须完整。

危险/不可用状态：
- 只降透明度，不用刺眼红色。

## 8. 篇章图与Opening
必须服从 `manifest/visual.override.v1.2.json` 和 `docs/runtime-asset-resolution-v1.0.md`。

图片：
- `object-fit: cover`；
- `object-position`逐卷读取；
- 禁止 `contain` 产生黑块；
- 标题放在底部渐变暗区，不留硬黑色空白。

Opening overlay建议：
- 底部：`rgba(11,7,15,.94)`；
- 中部：酒红/黑紫透明过渡；
- 上部：透明。

禁止重新使用当前统一的蓝绿色 `#07191e` / `#08181d` 遮罩。

## 9. 动态FX层
只允许轻量、低频、可降级：

### 红线
- 1~2条即可；
- 8~14秒完成一次缓慢漂移；
- opacity 0.18~0.42；
- 不要满屏蛛网。

### 狐火
- 3~7个小体积；
- 青白偏暖，不使用高饱和荧光绿；
- 每个生命周期4~9秒；
- 小幅上浮和呼吸，不高速乱窜。

### 金尘
- 低密度；
- 页面背景最多约12~20个可见粒子；
- 只作为景深层。

### 花瓣/雪/风沙/镜片
- 只按当前篇章Manifest的FX配置出现；
- 不是全局常驻。

### 呼吸光
- 当前卡片边框可做6~8秒一次的非常轻微暖金呼吸；
- 禁止强闪/霓虹灯效果。

## 10. 当前篇章动态主题
基础UI永远保持“夜漆·红线·灯金”。
当前篇章只允许覆盖：
- `--dl-chapter-accent`
- `--dl-chapter-glow`
- `--dl-current-art`

例如：
- 月红：暖红 / 花瓣
- 王权：冷金 / 剑光
- 南国：紫金 / 薄雾
- 真龙：沙金 / 龙影
- 镜花缘：银紫 / 镜光

不得按篇章彻底重绘整套UI颜色，否则视觉系统失去统一性。

## 11. 时代门
“古代 / 现代”双门不再使用绿色拱门。

古代：
- 暗赭 / 旧金 / 墨黑；
- 轻微古纸纹；
- 光从内部向外渗。

现代：
- 黑紫 / 暖红 / 金；
- 更干净玻璃质感；
- 可以有非常轻的城市散景，但不能赛博朋克。

双门都使用原创UI，不复制参考大佬卡布局/转场。

## 12. 缘忆
收藏卡应以“官方视觉本身”为主体，UI退后：
- 图片占卡片高度60~72%；
- 标题/来源/重播在底部薄玻璃层；
- 未解锁剧透模糊使用轻度模糊 + 暗纱，不要整卡灰死。

## 13. 缘音
保持成熟网易云播放器结构，不改业务逻辑。

外框从青绿改为黑紫酒红玻璃：
- 专辑名：暖金；
- 曲名：象牙白；
- 播放器iframe保持官方原样；
- “打开完整专辑”按钮使用酒红+金边；
- 显示 Lethe《狐妖小红娘》作为统一主专辑源。

## 14. 首页/首次Opening
无篇章时首页背景：
- 黑紫夜色；
- 一盏暖金“梦灯”光核；
- 极少狐火；
- 一条红线从远处缓慢穿过；
- 标题在光核稳定后出现。

时序（可略有调整）：
0.0s 黑场
0.2~0.8s 梦灯微亮
0.8~1.5s 红线出现
1.1~1.8s 标题显现
1.6~2.2s 前尘/今世入口解锁交互

总动画不超过约2.2秒即可进入操作，禁止强制播放长开场。

## 15. 性能与Android
- 不使用大面积持续Canvas重绘；优先CSS transform/opacity。
- 同时活跃动画元素建议 < 30。
- 页面切后台暂停非必要动画。
- `prefers-reduced-motion`与现有`dl-low-motion`必须保留。
- 低性能模式：只保留静态背景 + 红线1条 + 狐火0~2个。
- 不依赖hover。
- 360px宽度不可横向溢出。

## 16. 本轮绝对禁止施工项
静静做美化时禁止：
- 改MVU Schema；
- 改 `_时代/_当前篇章/_现代锁定`；
- 改世界书切换；
- 改时代单向推进；
- 改缘卷业务；
- 改网易云播放底层；
- 自行生成新篇章主海报；
- 自行搜索/替换官方素材；
- 把旧 `v1.0.1` AI图重新设为主视觉；
- 把黄风岭素材绑定M13；
- 复制外部参考卡CSS/布局/转场。
