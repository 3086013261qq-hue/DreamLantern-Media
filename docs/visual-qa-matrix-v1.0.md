## 动态资源QA
当前所有官方PV登记均属于“官方播放页已核”，**不是稳定裸MP4已核**。
因此下一版不得把 `video:null` 当成错误本身；错误是“明明没有稳定视频却用AI主视觉冒充官方动态Opening”。

正确行为：
- 有稳定官方直媒 → `official_video`
- 无稳定直媒但有官方海报 → `official_still_fx`
- 只有官方PV页无静态直媒 → `official_pv_source_pending_still`
- 官方素材未核 → `official_manga_visual_pending`

## 手机视觉QA
每一卷正式验收至少检查：
1. 360×800 / 412×915级别视口；
2. `object-fit: cover`；
3. 主体不能被标题条切脸；
4. 不允许上下大黑块；
5. 标题区域使用渐变遮罩而非硬黑底；
6. 外部官方图失败时只降级到生成fallback，再降级SVG；
7. 任何图片失败不得触碰MVU/世界书状态。

## 最终冻结条件
在以下条件完成前，不创建新正式Tag：
- `visual.override.v1.2.json` 已被卡体运行时正确读取；
- M01-M08与A02-A08均实际显示官方视觉而非生成图；
- A01/M09-M13 pending状态不会显示“官方已完成”假标签；
- Lethe专辑Track ID完成真实核验；
- 静静完成MVU背景/玻璃层/FX美化且不改变核心逻辑；
- Android实机QA通过。

通过后再冻结新Tag，建议 `v1.2.0` 或更高，不得继续使用旧 `v1.0.1` 作为新卡资源基线。
