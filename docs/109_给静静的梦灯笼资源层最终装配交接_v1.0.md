## 一、唯一资源入口

静静开始施工时只读取以下三个权威文件：

1. `manifest/chapter-runtime.v2.json`
   - 21卷资源目录的唯一运行时入口。
   - 旧 `poster/`、`thumb/`、`visual.override.v1.2.json` 不得主动浏览选材，只保留兼容/迁移参考。

2. `manifest/dynamic-runtime.v1.json`
   - 21卷 Opening 动态方式的唯一事实源。
   - 写死每卷是 `stable_official_mp4`、`official_primary_still_plus_fx` 还是 `brand_background_plus_fx`。

3. `manifest/fx-profiles.v1.json`
   - 所有伪动态参数唯一事实源。
   - 不得自行增加高负载粒子、绿色大底、霓虹、战斗HUD或重新设计特效语言。

辅助核对：
- `manifest/video-hunt-status.v1.json`：官方动态来源核验状态。
- `manifest/chapter-runtime.qa.v1.json`：仓库结构QA。
- `chapters/asset-dedupe-audit.v1.0.json`：旧生成资源SHA去重审计。

## 二、本轮装配原则

### 2.1 Opening固定解析链

必须严格按：

`稳定官方MP4 -> 官方静态图+伪动态 -> 品牌背景+伪动态 -> 旧生成故障fallback -> SVG故障fallback`

禁止：
- 把 YouTube/B站/微博播放器页当成 MP4。
- 抓取临时签名媒体。
- 下载或转码官方流媒体后重新托管。
- 从别卷借动态冒充当前卷。
- 因为没有MP4就启用旧AI图作为正常主视觉。

### 2.2 官方动态页用途

`official_embed_only / official_page_only` 只用于：
- 缘忆中的“查看官方动态”入口；
- 动态来源证明；
- 后续人工搜集真正稳定MP4时的线索。

Opening 默认不得塞多iframe。

### 2.3 当前MP4状态

目前 `stableDirectMp4 = 0`。
这不是Bug。
没有稳定MP4的卷必须按 `dynamic-runtime.v1.json` 使用伪动态。

未来若取得一条经核实、可长期公开运行的稳定官方MP4：
- 只修改对应卷 `stableMp4`；
- 将该卷 `openingMode` 切为 `stable_official_mp4`；
- 不允许因此改动MVU、世界书、卷序或时代锁。
