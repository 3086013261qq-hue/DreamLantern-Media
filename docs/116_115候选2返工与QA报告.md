复现：安装playwright、@sparticuz/chromium、@fontsource/noto-serif-sc；指定NODE_PATH和DREAMLANTERN_BROWSER_DEPS后，依次运行：

```
python assemble115.py source
python qa/make-harness115.py
node qa/test115.cjs
python assemble115.py json
python assemble115.py png
```

source阶段只生成源码与审计，json阶段只生成候选2 JSON，png阶段要求对应JSON已经存在且完全匹配，再替换候选1 PNG的chara/ccv3文本块；验证所有非卡数据块字节不变。

收尾采用独立提交：源码/manifest/QA → 候选2 JSON → 候选2 PNG。ZIP在这三步之后单独处理，不含MP4或运行时远程位图包。
