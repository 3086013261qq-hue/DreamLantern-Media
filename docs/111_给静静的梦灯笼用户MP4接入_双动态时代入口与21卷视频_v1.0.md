# 111_给静静的梦灯笼用户MP4接入_双动态时代入口与21卷视频_v1.2

日期：2026-10-20
状态：覆盖110中“双镜门”设计；双镜门正式作废。

## 1. 最重要的媒体架构

本工程禁止把 MP4 / 大图媒体字节打包进角色卡 PNG、JSON 或完整工程 ZIP 作为运行资源。

正式方式为：

`DreamLantern-Media GitHub 仓库 -> jsDelivr CDN -> SillyTavern/MVU 运行时远程加载`

CDN 基址：

`https://cdn.jsdelivr.net/gh/3086013261qq-hue/DreamLantern-Media@main/`

角色卡本体只保存：
- manifest；
- 相对媒体路径；
- HTML/CSS/JS 展示与交互逻辑；
- MVU业务状态。

严禁把文档中的“仓库托管MP4 / CDN远程MP4”误解为“本地MP4”。

## 2. 时代入口

1. 不再使用镜子。
2. 缘卷首页改为上下两块动态视频入口：
   - 上：前尘 / 古代，仓库资源 `incoming/mp4_raw/fengmian.mp4`
   - 下：今世 / 现代，仓库资源 `incoming/mp4_raw/xiandaifengmian.mp4`
3. 运行时均通过 jsDelivr CDN 请求。
4. 两个入口默认静音循环，避免同时出声。
5. 点击仍调用现有古代/现代选择业务；不得改MVU核心。

## 3. 篇章视频

用户上传的21段篇章视频全部保存在 `DreamLantern-Media/incoming/mp4_raw/`。

用户明确：素材编号遵循动画篇章顺序；正式接入只做：

`动画顺序 -> 对应篇章 -> 梦灯笼漫画卷号`

不需要逐段做人脸/场景识别，也不得把数字相同视为漫画卷号相同。

运行时：

`缘卷预览封面 -> 点击 -> 通过 CDN 播放该漫画卷映射后的仓库 MP4`

视频可保留原音轨；移动端若阻止有声自动播放，提供用户点击播放兜底。

## 6. 运行事实源

媒体运行事实源：
`manifest/user-media-runtime.v1.json`

动画顺序到漫画卷号的换位表：
`manifest/anime-to-manga-remap.v1.json`

运行脚本：
- `ui/dreamlantern.media111.js`
- `ui/dreamlantern.media111.css`

其中 `media111.js` 必须始终通过 jsDelivr BASE 拼接仓库相对路径；不得改成手机文件路径、SillyTavern本地路径或把视频base64塞进卡。
