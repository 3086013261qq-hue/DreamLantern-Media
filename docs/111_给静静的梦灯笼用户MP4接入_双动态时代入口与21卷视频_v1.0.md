## 1. 新最终方向

用户已上传完整视频素材，因此表现层改为：

1. 时代入口不再使用镜子。
2. 缘卷首页改为上下两块动态视频入口：
   - 上：前尘 / 古代，使用 `incoming/mp4_raw/fengmian.mp4`
   - 下：今世 / 现代，使用 `incoming/mp4_raw/xiandaifengmian.mp4`
3. 两块时代入口视频作为动态封面，默认静音循环，避免两个入口同时出声。
4. 点击逻辑仍使用现有古代/现代选择业务，不修改MVU。
5. 21个篇章各有本地 MP4，Opening 优先播放用户上传 MP4；失败才回退 runtime110 静态+FX。
6. 章节 MP4 允许保留音轨。若浏览器阻止有声自动播放，必须显示可点击播放控件或等待用户手势，不得因此让Opening黑屏。

## 4. 时代入口验收

Android/SillyTavern 必须肉眼看到：

- 上下两个宽幅动态视频卡，而非镜子、矩形暗斑或静态图；
- 古代入口显示 `fengmian.mp4`；
- 现代入口显示 `xiandaifengmian.mp4`；
- 两个视频均可循环；
- 两个入口同时存在时默认静音；
- 点击区域完整；
- 选择古代/现代后现有MVU和世界书逻辑完全不变。

## 5. 篇章Opening验收

每卷 Opening：

- 首选 `manifest/user-media-runtime.v1.json` 中对应 MP4；
- `data-dl-video-mounted="1"` 表示视频已正常挂载；
- 若有声 autoplay 被Android WebView拦截，状态允许为 `tap-to-play`，但用户必须能点一下正常播放；
- 视频错误时回退 runtime110 静态+FX；
- 视频错误不得影响卷选择、世界书切换、缘忆、网易云；
- 关闭Opening必须 pause + remove src + load，释放媒体资源；
- 任意时刻最多一个篇章 Opening 视频处于活动状态。
