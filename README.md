# DreamLantern-Media

《狐妖小红娘·梦灯笼》v1.0.1正式资源库，公开，默认分支main。

- manifest/：21卷Opening、资源索引、来源登记。
- poster/：21卷横版1440×960、手机版720×1080；9组原创场景意象母题。
- thumb/：21卷600×360轻量列表图。
- ui/：既有手札主题CSS、原创纸纹与轻量素材。
- fx/：原创狐火、红线、花瓣、微尘与薄雾。
- fallback/：21卷卡内同源轻量SVG，断网可用。

正式版本v1.0.1使用固定tag，禁止用@main作为长期卡体基线：
`https://cdn.jsdelivr.net/gh/3086013261qq-hue/DreamLantern-Media@v1.0.1/`

卡内只维护一个ASSET_BASE。资源加载失败不影响MVU、时代选择、缘卷、缘忆、缘音和世界书切换。无需重建业务世界书。

海报是为本项目制作的原创环境意象，不是官方动画/漫画截图或人物设定证据。官方宣传图片仅保留来源链接，不在此仓库镜像转载。LICENSE只覆盖原创代码与原创资源，不覆盖《狐妖小红娘》官方IP、音乐、角色、外部媒体或依赖。

音乐完全独立，未上传音频、Cookie或登录凭证。
