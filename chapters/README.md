# DreamLantern 分卷资源目录

本目录是后续装配的权威资源入口。静静/其他装配器必须先读 `chapters/index.json`，再只读取目标卷的 `resource.json`。

规则：
- 不得再通过浏览旧 `poster/` 目录自行挑图。
- `officialImages.primary/secondary` 是该卷允许的官方静态视觉。
- `videoCandidates` 是该卷允许继续核验的官方PV/动态来源；`stableDirectMp4` 为 null 时禁止猜MP4地址。
- 旧 `poster/<ID>/...` 仅作兼容fallback，不得标为官方主视觉。
- M13 新北山严禁使用黄风岭素材冒充。
- 当前v1.2.0旧路径继续保留，新增目录不破坏现有卡。
